# Guia do Jogador

A página do jogador é **pública** (sem login) e **somente leitura**. Foi feita para consulta rápida no celular durante a sessão.

## Acessar

`http://SEU-SERVIDOR/`

No topo, o link **Mestre** leva à tela de login do mestre.

## O que você vê

Em uma única página, de cima para baixo:

1. **Mapa de Baróvia** — locais com status por cor (Livre, Neutro, Hostil) e contador de missões.
2. **Missões** — nome, tipo (Busca/Reconhecimento/Controle), local, **DT**, notas e tropas alocadas.
3. **Tropas** — nome, descrição e quantidade disponível.
4. **Aliados** — nome, bônus e habilidade (informativo).
5. **Recursos** — Madeira, Pedra, Metais, Suprimentos e o total de tropas.

## Dicas

- Toque/clique em um nó do mapa para ver o nome do local.
- O número sobre o nó indica quantas missões partem dali.
- A página é responsiva e funciona bem em telas pequenas.
- Não há controles de edição: tudo é publicado pelo mestre.
